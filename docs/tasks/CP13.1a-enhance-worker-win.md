## Goal

HUMAN LEAD cài được worker trên máy RTX 3090 và RTX 3050 (Windows) bằng một script, worker chạy nền, tự kiểm GPU / NVENC / kết nối VM, và chờ việc từ VM (CP13.1b chưa có → nghỉ rồi hỏi lại, không lỗi). Khi CP13.1b merge, worker tự nhận việc theo giao thức E3.

## Scope

- In scope:
  - `tools/enhance_worker/` (không thuộc package `auto_short`, không thêm dependency vào `pyproject`):
    - `worker.py`: vòng lặp E4 — lease, tải nguồn có `Range` + sha256, `may-run` trước mỗi đoạn (E7; `yield_to_ollama` → giải phóng VRAM khi dừng), enhance `g10_p360` (tham số lấy từ lease, không hard-code), **đọc khung ở luồng riêng + batch trên GPU**, mã hóa NVENC (fallback libx264 nếu không có NVENC, ghi log), lưu đoạn + file trạng thái cục bộ, upload đoạn có `X-Sha256` với backoff khi mất mạng (đoạn chờ upload không chặn enhance), heartbeat, release; khởi động lại → đọc trạng thái, làm tiếp. HTTP bằng `urllib`. Mạng SRVGGNet dùng lại từ `scripts/enhance_bench_win.py` (tách module dùng chung hoặc sao chép có ghi nguồn).
    - `--self-test`: GPU (torch CUDA, tên card, VRAM), enhance một đoạn mẫu ngắn, NVENC, gọi `GET /api/enhance/may-run` qua tunnel (404 / 401 / kết nối được → in rõ trạng thái), in một dòng tổng kết.
    - `--once` / `--max-segments N` cho test; `--device cpu` để chạy trên VM.
    - Cấu hình worker: file JSON / TOML cạnh worker (URL `http://127.0.0.1:18080`, tên worker, token, `yield_to_ollama`, thư mục làm việc, dung lượng tối đa, batch size).
    - Log xoay vòng ra file.
  - `tools/enhance_worker/windows/setup-enhance-worker.ps1` và `auto-fix-enhance-worker.ps1`, cùng phong cách với `setup-gpu-node-v4.ps1` / `auto-fix-gpu-v4.ps1` của HUMAN LEAD (bản tham khảo chỉ đọc: `~/.cache/auto-short-cp13.1-ref/`, **không** chép IP / user / tên máy jump của HUMAN LEAD vào repo — để tham số, mặc định lấy từ block SSH `gpu-jump-v4` có sẵn):
    - Kiểm / cài: Python 3.11 (hướng dẫn nếu thiếu), venv, PyTorch CUDA (cu121), numpy, opencv-python-headless; ffmpeg Windows có NVENC (tải bản build chính thức hoặc hướng dẫn, kiểm `-encoders` có `h264_nvenc`); trọng số `realesr-general-x4v3.pth` (URL chính thức, kiểm sha256).
    - SSH: thêm block riêng `# >>> Enhance Worker v1 >>>` với `Host gpu-worker-v4` (`ProxyJump gpu-jump-v4`, cùng `IdentityFile`, `ExitOnForwardFailure yes`, `LocalForward 127.0.0.1:18080 127.0.0.1:8080`, keep-alive như v4); **không** sửa block / task Ollama v4.
    - Task Scheduler riêng: tunnel worker (wrapper tự nối lại) + worker (tự khởi động lại khi thoát), khi đăng nhập; tham số `-WorkerName`, `-YieldToOllama`, `-Token` (lưu trong file cấu hình worker, quyền chỉ user), `-Uninstall`.
    - Cuối setup chạy `--self-test`.
    - `auto-fix-enhance-worker.ps1`: dừng / chạy lại đúng task + tiến trình của worker, kiểm tunnel `18080`, chạy self-test, in trạng thái.
  - Server giả cho test: `tools/enhance_worker/fake_server.py` (chỉ dùng trong test / thử tay) hiện thực các route E3 tối thiểu theo ADR (lease, source Range, may-run, PUT seg kiểm sha256, heartbeat, release) — để test worker trước CP13.1b.
  - Tests `tests/test_enhance_worker.py` (chạy worker `--device cpu` với fake server trên VM, khung rất nhỏ): hết một tập ngắn; mất kết nối giữa chừng (dừng fake server) → enhance tiếp, upload khi có lại; khởi động lại worker → tiếp từ đoạn dở; `may-run: false` → dừng sau đoạn hiện tại; sai token → dừng có log; lease hết hạn → bỏ việc. ## Acceptance Criteria

1. `worker.py --device cpu` với fake server: enhance hết một tập ngắn, đoạn đúng số khung / kích thước, sha256 khớp.
2. Mất kết nối giữa chừng → enhance tiếp đoạn còn lại từ nguồn đã tải; có lại kết nối → upload đủ; khởi động lại worker → tiếp từ đoạn dở, không làm lại đoạn đã upload.
3. `may-run: false` → dừng sau đoạn hiện tại, hỏi lại theo chu kỳ; 401 → dừng, log rõ; 404 (VM chưa có API) → nghỉ, hỏi lại, không thoát.
4. Batch + luồng đọc khung có (kiểm bằng test đơn vị / log); tham số enhance lấy từ lease.
5. Script PowerShell: cú pháp hợp lệ (kiểm bằng `pwsh` nếu có trên VM, nếu không thì review kỹ + ghi rõ chưa chạy được); không chứa IP / user / mật khẩu của HUMAN LEAD; không đụng block / task Ollama v4; `-Uninstall` gỡ sạch phần của worker.
6. `--self-test` in kết quả rõ ràng cho cả trường hợp VM chưa có API.
7. `PYTHONPATH=<worktree>/src python -m pytest -q -n auto` PASS (chập chờn đã biết ghi rõ); `node scripts/framework-check.mjs` PASS.
