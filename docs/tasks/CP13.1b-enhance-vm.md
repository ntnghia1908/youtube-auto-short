## Goal

Phía VM của CP13.1: tập có nguồn < 720p tự được enhance (`g10_p360`) trên hai GPU Windows (3090 nhường Ollama, 3050 liên tục, chịu mất mạng), ghép thành `source_hd.mp4` trên VM, rồi Short / khai thị được render từ bản HD.

## Scope

- In scope: toàn bộ E1–E10 của ADR:
  - VM: `enhance.json` + quyết định E1 sau ingest; API `/api/enhance/*` (E3) + token (E8); lease / hết hạn / đoạn đã nhận (E2); ghép đoạn + audio → `source_hd.mp4` (làn `render`); render đọc nguồn HD + `render_key` (E6); trạng thái "đợi HD" + tự xếp render khi HD xong; tự dọn bỏ qua tập có HD (E5); config `[enhance]` (E9); UI (E10).
  - Worker Windows (E4): **không** thuộc task này — CP13.1a (`docs/tasks/CP13.1a-enhance-worker-win.md`); task này kiểm tích hợp bằng worker của CP13.1a chạy chế độ CPU trên VM.
  - Authority: ADR CP13.1 (ACCEPTED khi duyệt), cập nhật pointer ở CP7 R4 (nguồn render), CP8.3 (W5 trạng thái, W9 tự dọn, W7 API), CP8.9 K5, `docs/ai/project-profile.md`, README, `config.example.toml`.
- Out of scope: model video (temporal), GFPGAN; khung giờ chạy; "Enhance cả bộ kinh" một nút; enhance nguồn ≥ 720p; xóa nguồn gốc sau khi có HD (tay, như W9); upload YouTube.

## Acceptance Criteria

1. Ingest tập nguồn < 720p → `enhance.json` `wanted: true`; ≥ 720p → `false`; nút bật / tắt ghi đè; `.kt` dùng chung.
2. API E3: lease đúng thứ tự E2; tải nguồn có `Range`; `PUT` đoạn kiểm sha256 / số khung / kích thước, idempotent; lease hết hạn → về hàng đợi, giữ đoạn hợp lệ; sai token → 401; mật khẩu web không gọi được route worker.
3. Đủ đoạn → `source_hd.mp4` ghép frame-accurate (số khung = nguồn, audio nguyên), `enhance.json` `done`; thư mục đoạn xóa.
4. Tập `wanted` dừng ở "đợi HD" sau titling; HD xong → tự render + bài đăng tự soạn; "Render bằng bản gốc" render ngay; tập đã render rồi bật enhance: chưa đăng tự render lại, đã đăng giữ + nút "Render lại bản HD".
5. `render_key` đổi khi dùng HD; các stage khác không stale.
6. Tự dọn (W9 S5) bỏ qua tập có `source_hd.mp4`; dọn tay chỉ xóa nguồn gốc.
7. `may-run`: worker `yield_to_ollama` nhận `false` khi làn `ai` / job `post` hoạt động; worker khác `true`; "Tạm dừng enhance" → mọi worker `false`.
8. Worker (CPU trên VM, server test): chạy hết một tập ngắn; mất kết nối giữa chừng → làm tiếp offline, upload khi có lại; khởi động lại worker → tiếp từ đoạn dở.
9. UI E10 hiện đúng trạng thái / tiến độ / worker.
10. `PYTHONPATH=<worktree>/src python -m pytest -q -n auto` PASS (chập chờn đã biết ghi rõ); `node scripts/framework-check.mjs` PASS.
